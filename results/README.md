# /results

This directory contains the output of every benchmark, evaluation, and load test run.

Every file is timestamped and linked from the corresponding day's version doc.

**Honesty rule**: no fabricated metrics. Every number here came from an actual script run.

## File naming convention

- `day{N}_{description}_{YYYYMMDD_HHMMSS}.{json|csv}`
- Example: `day4_retrieval_benchmark_20241022_143000.json`
